# Summary

LEAVES.md open question 1 resolved: the REPL is not a generated leaf — `friedman repl` is intercepted as the first argv token in `run_cli` (`src/Friedman.jl`) and launches `start_repl()`; it never enters the registry tree. Inside, every `friedman <args>` invocation runs as `<args>` at the `friedman>` prompt, plus session state: `data use` loads a dataset once, later commands omit the positional (injected by tree-walking the registry), `estimate` results are cached in memory keyed by model type, and downstream commands (`irf`, `fevd`, `hd`, `forecast`, `predict`, `residuals`) reuse the cache instead of re-estimating. Session data and cached models vanish on exit — nothing is written unless `--save-model`/`--output` is used.

# Functions

| Leaf | Summary | Output tables |
|---|---|---|
| `friedman completions bash` | Print bash completion script | none (prints a script, not a table) |
| `friedman completions fish` | Print fish completion script | none (prints a script, not a table) |
| `friedman completions zsh` | Print zsh completion script | none (prints a script, not a table) |

Each completions leaf takes no arguments and one option:

| Option | Short | Type | Default | Description |
|---|---|---|---|---|
| `--output` | `-o` | `String` | `""` | Write script to file instead of stdout |

REPL-only commands (from `repl_dispatch`, not registry leaves):

| Command | Description |
|---|---|
| `data use <path>` | Load a CSV file into the session (`~` expanded; stems resolved as in `data load`) |
| `data use :<name>` | Load a bundled dataset (any name from `data list`, either separator spelling) |
| `data current` | Show session path, dimensions, and cached model types |
| `data clear` | Clear dataset and all cached results |
| `exit` / `quit` | Leave the REPL (also Ctrl-D / EOF) |

Behavior notes (from `src/repl.jl`, `docs/src/repl.md`):

- Data injection walks the registry tree (`_walk_command_path`, no extension sniffing) and inserts the session path after the command path when the leaf has no positional yet; an explicit positional overrides for that invocation. Loading new data clears all cached results.
- Model-type detection follows v1.0.0 family paths (`estimate|predict|residuals|forecast|test <family> <model>`); multiple model types coexist (`irf var` uses cached VAR, `irf bvar` cached BVAR); re-estimating replaces the cache entry.
- Tab completion is precomputed once per session (`CompletionIndex`: subcommand names per path plus `--option`/`--flag` names per leaf); quoted strings are respected when splitting input lines.
- Errors print a message and return to the prompt; the REPL never calls `exit()`, so exit codes do not apply inside a session.
- Completions scripts live in `completions/` (`friedman.bash`, `friedman.zsh`, `_friedman.fish`), regenerated by `docs/generate_cli_reference.jl`; a missing file is `env/completions-missing` (exit 6).

# Examples

```bash
friedman completions bash > /etc/bash_completion.d/friedman
friedman completions zsh --output _friedman
friedman repl
```

```text
friedman> data use :fred-md
friedman> estimate multivariate var --lags 4
friedman> irf var --horizons 20
friedman> fevd var --horizons 20
friedman> data current
friedman> data clear
friedman> exit
```
